# Arsip catatan batch

Catatan harian pengembangan (`batch-*`, `perbaikan-*`, `rilis-*`, cek kesehatan,
dsb) dipindah ke sini pada cabang `rapih/fondasi` supaya `docs/` hanya berisi
dokumentasi topikal yang aktif.

Isi folder ini **bukan sumber kebenaran** — hanya sejarah. Boleh dibaca untuk
melacak "kenapa dulu begini", tapi keputusan baru harus ditulis di dokumen
topikal atau `README.md` root.
