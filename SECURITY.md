# Kebijakan Keamanan / Security Policy

## Melaporkan celah (Bahasa Indonesia)

Jangan buka issue publik untuk celah keamanan. Kirim laporan lewat **GitHub Private Vulnerability Reporting** di tab Security repositori ini (Report a vulnerability). Sertakan: komponen (`api/`, `app/`, `dashboard/`, `agent-cpp/`, `native/`), langkah reproduksi, dampak, dan versi.

Komitmen kami:
- Konfirmasi penerimaan dalam 3 hari kerja.
- Penilaian awal dan rencana perbaikan dalam 10 hari kerja.
- Kredit pelapor di catatan rilis bila diinginkan.

Yang termasuk cakupan: kode di repositori ini dan layanan produksi XyCloudStore. Yang tidak termasuk: serangan DDoS volumetrik, rekayasa sosial, temuan dari pemindai otomatis tanpa bukti dampak, dan pengujian terhadap akun pengguna lain.

Versi yang didukung: rilis terbaru di cabang `main` dan APK versi terakhir yang dipublikasikan.

## Reporting a vulnerability (English)

Do not open a public issue for security problems. Use **GitHub Private Vulnerability Reporting** from this repository's Security tab (Report a vulnerability). Include the component (`api/`, `app/`, `dashboard/`, `agent-cpp/`, `native/`), reproduction steps, impact, and version.

Our commitment: acknowledgement within 3 business days, initial assessment and remediation plan within 10 business days, credit in release notes on request.

In scope: code in this repository and the XyCloudStore production services. Out of scope: volumetric DDoS, social engineering, unverified automated-scanner output, and testing against other users' accounts.

Supported versions: the latest release on `main` and the latest published APK.
